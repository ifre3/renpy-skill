# tl_check — tl 翻译文件质检 v3 分级细则

> 本文是 `scripts/checks/tl_check.py` 分级细则与崩溃边界的**唯一完整出处**；SKILL.md 与脚本表只留路由，不重复。
> 用法：`python scripts/checks/tl_check.py <项目路径> --lang schinese [--fix] [--add-tflag] [--max-examples N] [--glossary 术语表.xlsx] [--lang-ratio 0.75]`
> CLI 子命令：`renpy-tools-cli.py tlcheck`（已入 `all`；两条可选维度不在 `all` 里）。

## 与 checks/ 里同类的分工（2026-10-12）

同一次 `all` 里，同一批句子会被三个工具各看一遍，视角不同、**互不取代**。
重复报警不是 bug，但也别据此以为"跑一个就够"：

| 工具 | 视角 | 能自动修 | 适合什么时候用 |
|---|---|---|---|
| `tlcheck`（本工具） | 按**句**比对 old/new，分崩溃/显示/提示三级 | ✅ `--fix` | 默认用它；要修就用它 |
| `untranslated` | 只看 new 是否为空 / 等于 old | ❌ | 只要空译文清单，且要 `--csv` 导出 |
| `integrity` | 变量、标签结构、参数、转义 | ❌ | 要变量/转义层面的结构比对 |

实测（Dissonance 0.14）：空译文 20 条两边报的是同一批，是**同源**不是误报；
`tlcheck` 报 815 处而 `integrity` 报 117 处，是口径宽窄不同，不是谁漏了。

## 可选维度（默认关闭，规则取自 AiNiee 的 TranslationChecker）

这两条**不进 `all`、不改默认输出**，需要时显式传参才跑（2026-10-18 加）。

### `--glossary <术语表>` — 术语一致性（`[术语]` 级）

核对「原文命中术语表词条 → 译文有没有用上定稿译名」，只查这一个方向：译名出现
即达标，不追究位置，也不追究是否带括注（`艾琳（Eileen）` 仍算用了定稿译名）。

- 输入格式：`.xlsx`（AiNiee 三栏 `原文|译文|备注`，首行表头自动跳过）、`.jsonl`
  （每行 `{src,dst}`）、`.json`（扁平 `{src: dst}` 或 `[{src,dst}]`）三种都吃。
  xlsx 用标准库 `zipfile` + `ElementTree` 读，**不引入 openpyxl 依赖**。
- 匹配规则：纯 ASCII 词条按**整词边界**且大小写不敏感（`Ann` 不会命中
  `Announce`）；含非 ASCII 的按原样子串。单字母 ASCII 词条（`I`/`a`）与
  `dst` 为空的待定词条一律丢弃。
- 输出级别是新的 `[术语]`，计入退出码（1）；空译文与 `new==old` 的未翻译行由
  既有通道报，不在此重复。
- 读不到术语表文件是 **fail-closed**（报错退出 2）：显式点名的输入缺失时静默跳过
  会让检查变成假绿。

### `--lang-ratio <阈值>` — 语言不匹配分块判定（`[显示]` 级）

按 **20 行分块**统计「看得出是目标语言」的行占比，低于阈值（如 `0.75`）的块报
`语言不匹配`，并列出不像目标语言的行样本。

- **纯启发式**（假名 / 谚文 / CJK 汉字 / 拉丁字母占比），不是语言模型——所以只做
  **块级**判定：单行误判（中文句里夹个英文单词）在 20 行窗口里会被稀释。
- 只对 `schinese` / `tchinese`（zh）、`japanese`（ja）、`korean`（ko）、`english`
  （latin）生效；其他目标语言打印警告并跳过（没有可靠启发式，硬报就是噪音）。
- 样本过滤：没有语言信息的行（纯数字/符号）不参与；`new==old` 的未翻译行不进样本
  （那是「未翻译」通道的活）；块内有效样本不足 5 行不判。
- 目标中文时，含假名的行**不算达标**（与 `[显示] 残留日文假名` 同口径）。

## 三级报告

### 崩溃级（引擎显示到该行直接 raise）

- **未知文本标签 / 关闭无开放标签 / 不接受关闭的标签 / 未闭合大括号**：引擎在 `config.safe_text=False`（默认）时直接 raise；工具会读取项目配置自动降级。
- **未闭合 `[`**：渲染抛 "String ends with an open format operation"；原文本身未闭合则豁免译文。
- **`伪插值[非ASCII]`**（2026-10-13 新增，崩溃级）：译文里凭空出现的 `[嗯]`、`[你]`、`[总天数]` 之类。判据是剥掉字符串字面量与数字后，插值核心仍含非 ASCII 字母——合法的插值核心只会是变量/属性/下标等 ASCII 组合。修复：原句是纯文本就去掉方括号（写 `嗯`），想输出字面方括号须转义成 `[[`。
  来源 Dissonance_0.14 汉化 5 处真实闪退（`NameError: name '嗯' is not defined`）：译者想在句首加语气词，却套了方括号。原先只能靠人工从"[]插值不匹配"的显示级报告里辨认，现已自动判定。
- **`[]` 插值改名**（`[totaldays]`→`[total_days]`）：仍是显示级，需人工判断是否真的未定义——变量名确实存在就不崩。
- **译文裸 `%`**（`50%都是油`）在 safe_text=False 下也崩，写 `%%`。

### 显示级

- `{}` 标签新旧不一致、全角伪标签 `【i】`、空译文、`[]` 插值不匹配。
- 插值旗标丢失：原文 `[x!t]` 译文删成 `[x]`，值通道断；译文**补 `!t` 合法不报**。
- 新增换行符：译文换行数超过原文。
- 残留日文假名：译文夹 `そりゃ` 这类残片，汉字不算——`先輩` 不报；`--lang ja*`（目标语言为日语）时自动跳过。

### 提示级

- new==old 的未翻译行、含拉丁字母或日文假名的整句未翻译；**不计入退出码**。

## 行为细节

- 递归扫描 `tl/<lang>/` 全部子目录（发行项目常按 game/ 目录镜像分层，如
  `Girls Scripts/`），报告里的文件标识是相对 tl 的路径；只扫顶层的旧版会
  漏掉大多数翻译文件（实测 AfterDark 0.26：顶层 10 个 vs 实际 70 个）。
- 识别项目自定义文本标签：`config.custom_text_tags["x"]` /
  `renpy.register_text_tag("x")` 并入已知标签，`config.self_closing_custom_text_tags`
  按不接受关闭处理——动态文本游戏（kinetic_text_tags 类）的 `{chaos}`/`{bt}`
  不再误报"未知标签/关闭无开放标签"。
- 按引擎源码模拟：标签大小写敏感、花括号内空格不剥离。
- 说话人正则支持带点表达式（`mc.name`）、下标（`the_group[0]`）、引号字面量（`"Janitor"`）——Lab Rats 2 类游戏台词不再漏检。
- `--fix` 自动修机械性问题：`%(变量名被翻)` 还原、`{ i }`/`{/B}` 规范化。
- `--fix --add-tflag`：给译文中与原文一致的裸插值补 `!t` 旗标（值先过 strings 表，`[mc.name]` 中文名显示必需；`[x:.1f]` 等格式规格与含裸 `!` 的表达式自动跳过）。
- 输出行号是**译文行**，直接定位要改的行。

## `--settle`：结构层修复

`tl_check --fix` 只做「同一个标签写得难看」的规范化。机翻管线真正大量的损伤是
**句子结构被破坏**，需要 `--fix --settle`，实际执行在 `checks/tag_repair.py`（独立模块，自带 19 条单元测试）：

| 损伤形态 | 引擎后果 | 修复方式 |
|---|---|---|
| `{i>…` `{i]…` `{/i>` | 整句失衡 → raise | 畸形右符号补正成 `}` |
| `{我}` `{必须}` | 当成未知标签 → raise | 退化为字面文本（本来就是正文） |
| `…。{/i}` 孤立闭合 | 关闭无开放 → raise | 按原文包裹范围补开标签 |
| `[PN]` `[Pg]` | 插值大小写敏感 → KeyError | 还原大小写 |
| `[阿梓子羁绊]` | 变量被当文本翻译 → KeyError | 按集合差还原原名 |
| `[chyo_bond]` | 变量名拼错 → KeyError | 编辑距离 ≤2 近似匹配还原 |

三条约束（违反即不修）：

1. **原文注释行是唯一真值**。只在同 translate 块的原文本身标签平衡时才动手；
   原作自带标签错误时不猜（译文不为上游 bug 背锅）。
2. **不移动自然语言**。只重写符号层，一个汉字都不挪；修复后的汉字序列必须与修复前
   完全一致（由 `test_tag_repair.py::test_chinese_content_preserved` 锁住）。
3. **健康句不许动**。标签已平衡的句子原样返回，避免改写 `{size=}` 参数或
   `{}{size}` 这类已平衡形态。

实测（Dissonance 0.14 的 44387 句 schinese）：307 个破损句 100% 修复，0 处误伤健康句。
修完必须用 SDK lint 复核 —— 静态工具的自证不等于引擎的裁决。
